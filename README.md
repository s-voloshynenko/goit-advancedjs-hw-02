# goit-advancedjs-hw-02

GoIT Advanced JS homework 2: asynchronous JavaScript and promises. Built with
[Vite](https://vitejs.dev/) on top of the
[vanilla-app-template](https://github.com/goitacademy/vanilla-app-template).

- `1-timer.html`: countdown timer to a date picked with
  [flatpickr](https://flatpickr.js.org/).
- `2-snackbar.html`: promise generator that shows the result with
  [iziToast](https://izitoast.marcelodolza.com/).

## Scripts

```bash
npm install     # install dependencies
npm run dev     # start the dev server
npm run build   # build into dist/
```

Pushing to `main` builds the project and deploys `dist` to the `gh-pages` branch
via GitHub Actions.
